# Getting familiar with the concept

## What is container.vc?

**container.vc** is a **VeraCrypt-encrypted virtual disk**. Think of it like a safe inside a computer: from the outside, it looks like an unreadable data file, but inside it can contain many folders and documents. Only with the correct password or keyfile can we mount it and open it like a regular drive.

Along with it, I saw the file **wordlist**. This suggests a **dictionary attack**. Based on these clues, I predicted that **Hashcat** could be used to try the passwords from the **wordlist**, find the correct one, then use it to **mount the container** and inspect its contents.
